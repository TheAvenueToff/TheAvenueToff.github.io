Privacy policy

CrackBoard · Last updated October 13, 2026

What it accesses

CrackBoard asks Google for read-only access to calendars (the calendar.readonly permission). It cannot create, change or delete events.

How the data is used

Event titles, times and locations are shown on one picture frame in the owner's home. Nothing else is done with them.

Storage and sharing

A short-term copy of upcoming events and the sign-in token are kept on the owner's private server, readable only by the dashboard. Data is never sold, shared, used for ads or used to train AI models.

Google API data

CrackBoard's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from Google Account permissions. Stored event copies are deleted when the dashboard is removed.
